Jot 0.7.3

Fixes every transcription failing with "The network connection was lost" or "Request timed out" on macOS 27 — on both providers at once.

  • Uploads no longer stall on HTTP/3. macOS 27 started sending Jot's audio uploads over HTTP/3 (QUIC). On a network whose router advertises an IPv6 link MTU below 1500, the system's QUIC stack never recovers from the resulting "Message too long" errors, so every part of every meeting failed on Groq and OpenAI alike. Jot now keeps its transcription, Notion and Claude Code requests on HTTP/2 over TCP, where the same upload completes in about a second.
  • The protocol shows in Console. Each upload logs the protocol it negotiated (h2 expected) and warns if HTTP/3 sneaks back in, so a repeat is diagnosable at a glance.
  • Your failed meetings are still in the Watch Folder. After updating, open the Audit Log and press Retry on each failed row — every part is re-uploaded as one meeting.
